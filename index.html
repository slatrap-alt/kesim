Bulut erişim izni hakkında

“permission-denied” hatası alırsan Firebase Console → Firestore Database → Rules bölümünde, mevcut kurallarını koruyarak aşağıdaki bloğu match /databases/{database}/documents içine ekle ve yayımla. Bu kural yalnızca giriş yapan hesabın kendi teklif ve fiyat kayıtlarına izin verir.

match /acanlar_fiyat_v2/{userId}/{document=**} {
  allow read, write: if request.auth != null
                     && request.auth.uid == userId;
}
